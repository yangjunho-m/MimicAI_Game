# MIMIC.AI

사람이 AI처럼 그림을 그려 다른 플레이어를 속이는 2~4인 파티 드로잉 게임입니다.

## 플레이

1. 방을 만들고 데모 플레이어를 2~4명 추가합니다.
2. 모든 플레이어가 같은 제시어를 보고 차례로 그림을 그립니다.
3. 게임이 같은 조건의 AI 그림 한 장을 추가합니다.
4. 익명 그림 중 AI가 그린 그림에 투표하고 정체를 확인합니다.

온라인 방에서는 초대 코드 또는 초대 링크로 최대 4명이 각자의 기기에서 접속합니다. 게임 시작, 제시어, 그림 제출과 투표 갤러리는 WebRTC P2P로 실시간 동기화됩니다. 별도의 계정이나 멀티플레이 서버는 필요하지 않습니다.

## 실행

Node.js 22 이상에서 `npm install`, `npm run dev`로 실행합니다.
GitHub Pages 공개판은 비밀키 노출을 막기 위해 내장 AI 스케치를 사용합니다. GPT Image API 연결 코드는 별도의 서버리스 백엔드에서 운영하는 것을 전제로 합니다.

## 외부 에셋

외부 이미지, 아이콘, 폰트, 사운드를 사용하지 않습니다. UI와 내장 자동 스케치는 프로젝트 코드로 직접 제작되었습니다.
